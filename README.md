#  Data Analyst Project

##  Overview

This project demonstrates an end-to-end data analysis workflow. It covers loading data using Python, performing Exploratory Data Analysis (EDA), cleaning the dataset, running SQL queries on MySQL Server, and building an interactive dashboard in Power BI. The final insights are summarized in a report and presentation.

##  How to Run

1. **Clone the repository**

   ```bash

   ```

2. **Install dependencies**

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

3. **Run Python scripts / Notebook**

   * Open Jupyter Notebook
   * Execute all cells step by step

4. **Setup MySQL**

   * Import cleaned dataset into MySQL
   * Run SQL queries from provided scripts

5. **Open Power BI**

   * Load dataset file
   * Open `.pbix` file to view dashboard
